This project is a **RESTful API** for managing Products and Product Details, built using **Spring Boot**, **Spring Data JPA**, **MySQL**, **DTO Pattern**, and a **Global Exception Handler**.  
The project also includes **unit tests** written using **JUnit 5** and **Mockito**.

---

## 🚀 Technologies Used

- **Java 17**
- **Spring Boot**
- **Spring Web**
- **Spring Data JPA**
- **MySQL Database**
- **DTO Pattern + MapStruct**
- **Global Exception Handling**
- **JUnit 5**
- **Mockito**
- **Lombok** *(optional)*
